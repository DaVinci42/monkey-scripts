# Monkey Scripts

Tiny scripts fixing websites that were apparently finished.

## Scripts

- **[Not Interested](scripts/x-not-interested/x-not-interested.user.js)**  
  Adds a native-looking shortcut to mark X/Twitter posts as not interested, without flashing the post menu.

## Install

1. Install Tampermonkey, Violentmonkey, or another userscript manager.
2. Open a `.user.js` file from the list above.
3. Select **Raw**, then confirm the installation.
